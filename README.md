# BlockCoreDiamond

BlockCoreDiamond is a decentralized, multi-node, fault-tolerant framework that leverages a distributed hash table for scalable real-time data processing.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/BlockCoreDiamond.git`
2. `cd BlockCoreDiamond`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure BlockCoreDiamond, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
